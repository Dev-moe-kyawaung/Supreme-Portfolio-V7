### 📦 GitHub Pages
```bash
# 1. Create repository on GitHub:
# Name: Supreme-Portfolio-V7-Enterprise
# Description: Supreme Portfolio V7 - Ultimate Enterprise Mastery Edition

# 2. Add remote and push
git remote add origin https://github.com/Dev-moe-kyawaung/Supreme-Portfolio-V7-Enterprise.git
git branch -M main
git push -u origin main

# 3. Enable GitHub Pages:
# Settings → Pages → Source: GitHub Actions
# OR
# Settings → Pages → Source: Deploy from branch → main → / (root)

# 4. Your site will be live at:
# https://dev-moe-kyawaung.github.io/Supreme-Portfolio-V7-Enterprise/

# 5. GitHub Actions will auto-deploy via .github/workflows/deploy-github-pages.yml
```

### 📦 GitLab Pages
```bash
# 1. Create project on GitLab:
# Project name: supreme-portfolio-v7
# Visibility: Public

# 2. Add remote and push

git push -u gitlab main

# 3. GitLab CI/CD auto-deploys using .gitlab-ci.yml
```

### 🌐 Custom Domain Setup
```bash
# 1. Create CNAME file with your domain (already included)
echo "yourdomain.com" > CNAME

# 2. Configure DNS records:
# For GitHub Pages:
# A Records:
#   185.199.108.153
#   185.199.109.153
#   185.199.110.153
#   185.199.111.153
# CNAME: www → Dev-moe-kyawaung.github.io

# 3. Update repository settings:
# Settings → Pages → Custom domain → yourdomain.com
# Check "Enforce HTTPS"
```

### ☁️ Cloudflare Setup (Recommended)
```bash
# 1. Add your domain to Cloudflare
# 2. Update nameservers to Cloudflare

# 3. DNS Records:
A @ 185.199.108.108 (Proxied - orange cloud)
A @ 185.199.109.108 (Proxied)
A @ 185.199.110.108 (Proxied)
A @ 185.199.111.108 (Proxied)
CNAME www Dev-moe-kyawaung.github.io (Proxied)

# 4. SSL/TLS Settings:
# SSL/TLS encryption: Full (Strict)
# Always Use HTTPS: ON
# Minimum TLS Version: 1.2

# 5. Performance Settings:
# Auto Minify: HTML, CSS, JS all ON
# Brotli: ON
# Rocket Loader: ON
# Mirage: ON
# Polish: ON (Lossless)

# 6. Page Rules:
# URL: yourdomain.com/*
# Settings: Cache Level: Cache Everything
#           Edge Cache TTL: 7 days
```

## 🔍 SEO & Search Engine Verification

### Google Search Console
```html
1. Go to https://search.google.com/search-console
2. Add property: URL prefix
3. URL: https://dev-moe-kyawaung.github.io/Supreme-Portfolio-V7-Enterprise/
4. Choose verification method: HTML file
5. Download the verification file
6. Rename to match and place in /verification/ folder
7. Upload to your site
8. Click "Verify"
9. Submit sitemap: https://dev-moe-kyawaung.github.io/Supreme-Portfolio-V7-Enterprise/sitemap.xml
```

### Microsoft Bing Webmaster
```html
1. Go to https://www.bing.com/webmasters
2. Add site
3. Choose verification method: HTML file
4. Download the verification file
5. Rename to match and place in /verification/ folder
6. Verify
7. Submit sitemap: sitemap.xml
```
