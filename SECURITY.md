# 🔐 Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 7.x     | ✅ Active support  |
| 6.x     | ✅ Security fixes  |
| < 6.0   | ❌ Not supported   |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by:

1. **Email**: moekyawaung@programmer.net
2. **Encrypted communication**: GPG key available at Keybase
3. **Response time**: Within 48 hours

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

## Security Measures

- HTTPS enforced
- CSP headers configured
- XSS protection
- No sensitive data in repository
- Regular dependency updates
- Code review process

## Bug Bounty

At this time, there is no formal bug bounty program. However, valid security reports will be acknowledged.
